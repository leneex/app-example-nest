# Nest

Пример приложения [Nest](https://nestjs.com/), которое можно развернуть без настройки.

## Параметры деплоя

| Поле | Значение |
| --- | --- |
| Сборка | Railpack |
| Путь до директории проекта | `/` |
| Команда установки зависимостей | оставьте пустым |
| Команда сборки | оставьте пустым |
| Команда запуска | `npm run start:prod` |
| Порт приложения | `3000` |
| Путь проверки состояния | `/` |

Railpack ставит зависимости и собирает проект (`npm run build`). Команда запуска
`npm run start:prod` запускает собранный `dist/main.js`; без неё Railpack запускает
`npm run start`, а он собирает проект заново при каждом старте. Приложение слушает порт из
переменной окружения `PORT` — её передаёт платформа, — а без неё `3000`.

В демо нет `package-lock.json`: версии пакетов выбираются при сборке по диапазонам из
`package.json`.

## <a name="dev"></a>Локальный запуск проекта

```bash
# установка зависимостей
npm install

# запуск в режиме разработки с отслеживанием изменений
npm run start:dev

# сборка и запуск для продакшн
npm run build
npm run start:prod
```

Нужен Node.js 24.15 или новее (в ветке 22 — 22.22.3 или новее).
