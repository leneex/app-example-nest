# Nest

Пример приложения [Nest](https://nestjs.com/), которое можно развернуть без настройки.

## <a name="dev"></a>Локальный запуск проекта

```bash
# установка зависимостей
npm install

# запуск в дев режиме с отслеживанием изменений
npm run start:dev

# сборка приложения
npm run build

# запуск приложения
npm run start:prod
```
